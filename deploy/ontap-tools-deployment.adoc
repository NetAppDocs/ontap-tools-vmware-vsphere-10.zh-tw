= 部署 ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
將 ONTAP tools for VMware vSphere 部署為支援 NFS 和 VMFS 資料存放區的超小型單節點應用裝置。部署程序最多需要 45 分鐘。

.開始之前
如果部署的是超小型單一節點組態，內容庫是選用的。對於多節點或高可用性部署，內容庫是必要的。

在 VMware 中，內容庫用於儲存虛擬機器範本、vApp 範本及其他檔案。使用內容庫可簡化部署，因為在範本操作期間不需要直接網路存取。

在建立內容庫之前：

* 在共享資料儲存上建立內容庫，以便叢集中的所有主機都可以存取它。
* 在部署 ONTAP tools for VMware vSphere OVA 之前，請先建立內容庫。
* 部署後，將 OVA 範本保留在內容庫中。



NOTE: 如果您打算稍後啟用 HA，請將 ONTAP tools VM 部署在 ESXi 叢集或資源池，而不是直接部署在 ESXi 主機上。

建立內容庫：

. 從 https://mysupport.netapp.com/site/products/all/details/otv10/downloads-tab["NetApp 支援網站"^]下載 ONTAP tools for VMware vSphere 二進位檔案 （_.ova_） 和已簽署憑證。
. 登入 vSphere Client。
. 從 vSphere Client 選單中，選取*內容庫*。
. 選擇 *Create*。
. 輸入名稱，建立內容庫。
. 開啟您建立的內容庫。
. 選擇 *Actions* > *Import item*，然後匯入 OVA 檔案。



NOTE: 如需更多資訊，請參閱 https://blogs.vmware.com/vsphere/2020/01/creating-and-using-content-library.html["建立及使用內容庫"]。


NOTE: 部署前，將叢集分散式資源調度器（DRS）設定為保守模式，以防止安裝期間發生虛擬機器移轉。

ONTAP tools for VMware vSphere 最初部署為非 HA 組態。從 ONTAP tools 10.6 開始，CPU 熱新增和記憶體容量熱插拔功能預設為啟用。若要後續擴展至 HA，則必須啟用這些功能。

.步驟
. 從 https://mysupport.netapp.com/site/products/all/details/otv10/downloads-tab["NetApp 支援網站"^]下載 ONTAP tools OVA 檔案和已簽署憑證。如果您已將 OVA 匯入內容庫，請跳過此步驟。
. 登入 vSphere 伺服器。
. 前往要部署 OVA 的資源池、叢集或主機。
+

IMPORTANT: 不要將 ONTAP tools VM 儲存在其所管理的 vVols 資料儲存區上。

. 從內容庫或本機系統部署 OVA 檔案。
+
|===


| 從本機系統 | 從內容庫 


| a. 按一下滑鼠右鍵並選取 * 部署 OVF 範本 ...* 。 b. 從 URL 選擇 OVA 檔案或瀏覽至其位置，然後選取 * 下一步 * 。 | a. 移至內容庫並選取您要部署的文件庫項目。 b. 從此範本中選取 * 「動作」 * > * 「新增虛擬機器」 * 
|===
. 在「選擇名稱和資料夾」中，輸入虛擬機器名稱和位置。
. 選取電腦資源，然後選取 * 下一步 * 。（可選）選中複選框以 * 自動啓動已部署的 VM* 。
. 檢閱範本的詳細資料，然後選取 * 下一步 * 。
. 閱讀並接受授權合約、然後選擇 * 下一步 * 。
. 選取組態和磁碟格式的儲存設備，然後選取 * 下一步 * 。
. 選取每個來源網路的目的地網路，然後選取 * 下一步 * 。
. 在「自訂範本」視窗中，輸入所需的值。image:../media/custom-temp-p2.png["自訂模板"]
+
[IMPORTANT]
====
「自訂範本」頁面上的值是成功部署所必需的。

請特別注意以下欄位：

** *主機名稱*：輸入 ONTAP tools VM 主機名稱。請使用有效的主機名稱格式。
** *ONTAP tools IP address*：這是用於存取 ONTAP tools 的主要管理介面。
** *IPv4 位址*：這是用於診斷 shell 和 SSH 存取以進行故障排除和維護的節點 IP 位址。


如果您使用 DNS 名稱作為主機或 vCenter 的名稱，請確保這些名稱在 DNS 中能夠正確解析。

====
+

NOTE: vCenter 主機名稱是部署ONTAP工具設備的 vCenter Server 執行個體的名稱。

+
如果您在雙 vCenter Server 拓撲中部署 ONTAP tools，其中應用裝置託管在一個 vCenter 執行個體中並管理另一個執行個體，請為託管 ONTAP tools 的 vCenter 執行個體指派受限角色。建立專用 vCenter 使用者和角色，僅授予部署 OVF 範本所需的權限。如需詳細資訊，請參閱 link:../concepts/rbac-vcenter-use.html#vsphere-object-hierarchy["適用於 VMware vSphere 10 的 ONTAP 工具隨附的角色"]。

+
對於由 ONTAP tools 管理的 vCenter 執行個體，請確保 vCenter 使用者帳戶具有系統管理員權限。

+
** 主機名稱必須包含字母（A-Z、a-z）、數字（0-9）和連字號（-）。對於雙堆疊，請指定對應到 IPv6 位址的主機名稱。
+

NOTE: 不支援純 IPv6。支援混合模式，即 VLAN 中同時包含 IPv6 和 IPv4 位址。

** ONTAP tools IP 位址（以前稱為負載平衡器）是 ONTAP tools Manager (`\https://<ip>:8443/virtualization/ui/`、API 呼叫以及從 vCenter UI 進行外掛存取的外部端點。
** ONTAP tools 虛擬 IP 位址（以前稱為節點互連）指派給 Kubernetes API (kube-api) 伺服器，並作為 Kubernetes 控制平面的虛擬 IP。
** IPv4 位址是對應到指定主機名稱的節點管理位址，用於診斷 shell 和 SSH 存取。


. 查看 * 準備完成 * 視窗中的詳細資料、選取 * 完成 * 。
+
部署工作開始時，進度會顯示在 vSphere 工作列中。

. 如果您沒有選擇自動開機，請在工作完成後啟動虛擬機器。


從虛擬機器 Web 控制台追蹤安裝進度。

如果 OVF 表單有差異，系統會彈出對話方塊提示修正行動。使用 Tab 鍵瀏覽，進行必要的變更，然後選取「確定」。您有三次機會解決問題。如果問題在三次嘗試後仍然存在，安裝將停止，您應在新的虛擬機器上重試安裝。
