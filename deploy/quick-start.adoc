= VMware vSphere ONTAP 工具快速入門
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
透過此快速入門設定 ONTAP tools for VMware vSphere。

首先完成這些核心工作，使 ONTAP tools 能夠正常運作，以進行初始設定和資源配置。然後根據您的環境和保護需求完成選用工作。

最初，您需要將 ONTAP tools for VMware vSphere 部署為超小型 （XS） 單一節點組態，為 NFS 和 VMFS 資料存放區提供核心服務。如果您需要為每個服務新增更多容器、更高的恢復能力或 vVols 資料存放區和高可用度 （HA），請先完成此工作流程，然後再繼續進行擴充。如需詳細資訊，請參閱 link:../deploy/ha-workflow.html["HA 部署工作流程"]。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["一"]規劃您的部署
[role="quick-margin-para"]
確認您的環境已準備好進行支援的部署。驗證您的 vSphere、ONTAP 和 ESXi 主機版本是否與 ONTAP tools 版本相容。分配足夠的 CPU、記憶體容量和磁碟空間。根據您的安全性規則，您可能需要設定防火牆或其他安全性控制措施以允許網路流量。

[role="quick-margin-para"]
確保 vCenter 伺服器已安裝且可存取。

[role="quick-margin-list"]
* https://imt.netapp.com/matrix/#welcome["互通性對照表工具"]
* link:../deploy/prerequisites.html["適用於 VMware vSphere 的 ONTAP 工具的要求和設定限制"]
* link:../deploy/pre-deploy-checks.html["開始之前"]


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["二"]部署適用於 VMware vSphere 的 ONTAP 工具
[role="quick-margin-para"]
部署 ONTAP tools 設備，為 NFS 和 VMFS 資料存放區建立基礎服務。

[role="quick-margin-para"]
如果您計劃擴充 vVols 資料存放區和 HA 的部署，請先完成此工作流程。在 ONTAP tools for VMware vSphere 10.6 中，CPU 熱新增和記憶體容量熱插拔預設為啟用。

[role="quick-margin-para"]
部署期間，請仔細檢查「自訂範本」欄位，特別是主機名稱、ONTAP tools IP 位址使用情況和 DNS 需求。

[role="quick-margin-list"]
* link:../deploy/ontap-tools-deployment.html["部署適用於 VMware vSphere 的 ONTAP 工具"]


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["三"] 註冊並安裝 vCenter 用戶端外掛程式
[role="quick-margin-para"]
新增 vCenter 伺服器執行個體以註冊 vCenter 用戶端外掛程式並套用所需的權限和角色。新增 vCenter 伺服器執行個體時，ONTAP tools 會註冊遠端外掛程式、套用自訂外掛程式和 API 權限、建立自訂角色，並在 vSphere 使用者介面中新增外掛程式捷徑。

[role="quick-margin-list"]
* link:../configure/add-vcenter.html["將 vCenter Server 執行個體新增至ONTAP工具"]


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["四"] 配置儲存後端
[role="quick-margin-para"]
連接 ONTAP 儲存資源，以便 ONTAP tools 可以資源配置和管理資料存放區。向 ONTAP 叢集新增儲存設備後端。在多租戶環境中，如果 vCenter 伺服器與租戶 SVM 關聯，請使用 ONTAP tools Manager 新增叢集。然後將儲存設備後端與 vCenter 伺服器關聯，為該 vCenter 執行個體建立全域映射。

[role="quick-margin-para"]
使用 ONTAP tools 介面，以叢集或 SVM 憑證新增本機儲存設備後端。這些儲存設備後端僅限單一 vCenter。當您在本機使用叢集憑證時，關聯的 SVM 會自動對應到 vCenter，以進行 vVol 或 VMFS 管理。對於 VMFS 管理（包括 SRA），ONTAP tools 支援 SVM 憑證，而無需全域叢集。

[role="quick-margin-list"]
* link:../configure/add-storage-backend.html["新增儲存後端"]
* link:../configure/associate-storage-backend.html["將儲存後端與 vCenter Server 執行個體建立關聯"]

== 可選的後續任務

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["一"] 設定 ONTAP 使用者角色和權限
[role="quick-margin-para"]
設定自訂 ONTAP 角色以實現最小權限存取，而非使用預設系統管理員帳戶。

[role="quick-margin-list"]
* link:../configure/configure-user-role-and-privileges.html["設定 ONTAP 使用者角色和權限"]


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["二"] 升級多個 vCenter Server 執行個體的憑證
[role="quick-margin-para"]
升級憑證，以便在多個 vCenter Server 執行個體之間使用受信任的憑證型通訊。

[role="quick-margin-list"]
* link:../manage/certificate-manage.html["管理憑證"]


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["三"]配置 SRA 保護
[role="quick-margin-para"]
啟用 SRA 功能，為 NFS 和 VMFS 資料存放區設定災難恢復保護。

[role="quick-margin-list"]
* link:../manage/enable-services.html["為 VMware vSphere 服務啟用 ONTAP 工具"]
* link:../protect/configure-on-srm-appliance.html["在 VMware Live Site Recovery 應用裝置上設定 SRA"]


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["四"] 啟用 SnapMirror 主動同步保護
[role="quick-margin-para"]
使用 SnapMirror 主動同步設定主機叢集保護，以保護 VMFS 資料儲存。在 ONTAP 系統中，建立所需叢集和 SVM 的對等連接，然後在 ONTAP tools 中設定保護。此選項僅適用於 VMFS 資料儲存。

[role="quick-margin-list"]
* link:../protect/config-proximity.html["使用 ONTAP tools 設定叢集以保護資料存放區"]
* link:../protect/protect-multiple-ds.html["保護叢集中的資料存放區"]


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-5.png["五"] 為您的 ONTAP tools 部署設定備份與還原
[role="quick-margin-para"]
設定備份與還原機制，以保護 ONTAP tools 組態並從故障中快速復原。

[role="quick-margin-para"]
在 ONTAP tools for VMware vSphere 10.6 中，備份預設為啟用，每 10 分鐘執行一次。

[role="quick-margin-list"]
* link:../manage/backup-settings.html["編輯備份設定"]
* link:../manage/recover-backup.html["恢復ONTAP工具設定"]
