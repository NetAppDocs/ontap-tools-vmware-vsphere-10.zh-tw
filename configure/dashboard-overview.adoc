= 了解 ONTAP tools for VMware vSphere 儀表板
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
從 vCenter 用戶端的捷徑區段中選取 ONTAP tools for VMware vSphere 外掛圖示，以開啟儀表板，其中會總結外掛、資料存放區和 vCenter Server 資料的狀態。

在增強連結模式 (ELM) 中，會出現 vCenter Server 下拉選單。選擇一個 vCenter Server 來檢視其資料。此下拉式選單在插件的所有清單視圖中均可使用。當您在一個頁面上選擇一個 vCenter Server 時，請在外掛程式中切換標籤時，該 vCenter Server 保持不變。image:../media/remote-plugin-dashboard.png["儀表板總覽"]

在總覽頁面，您可以執行 *Discovery* 行動，以偵測 vCenter 層級上新增或更新的儲存設備後端、主機、資料儲存區及保護狀態或關係。無需等待排程的探索，即可執行隨需探索。

如果向受保護的主機叢集新增主機，保護設定將變更為*部分保護*。

若要解決此狀態，請開啟「修改叢集組態」，將主機指派給正確的網站（來源或目標），然後選取「修改」。


NOTE: 只有在您擁有執行探索所需的權限時，才會啟用 *Discovery* 按鈕。

提交發現請求後，您可以在最近任務面板中追蹤操作的進度。

儀表板有幾張顯示系統不同元素的卡片。下表顯示不同的卡片及其代表的內容。

|===


| * 卡片 * | *說明* 


| 狀態 | 狀態卡顯示儲存後端數量以及儲存後端和 VASA Provider 的整體健全狀況狀態。當所有儲存後端狀態正常時，儲存後端狀態顯示 *Healthy* ，如果任何儲存後端出現問題（ Unknown/Unreachable/Degraded 狀態），則顯示 *Unhealthy* 。選取工具提示以開啟儲存後端的狀態詳細資料。您可以選取任何儲存後端以取得更多詳細資料。*Other VASA Provider states* 連結會顯示在 vCenter Server 中註冊的 VASA Provider 目前狀態。 


| 儲存設備後端 - 容量 | 此卡片顯示所選 vCenter Server 執行個體所有儲存後端的已使用容量和可用容量匯總。對於 ASA r2 儲存系統，由於儲存是分散的，因此不顯示容量資料。 


| 虛擬機器 | 此卡片顯示按效能指標排序的前 10 個虛擬機器。您可以選擇標題，按所選指標以遞增或遞減順序排列前 10 個虛擬機器。卡片上所做的排序和篩選變更將持續保留，直到您變更或清除瀏覽器快取為止。 


| 資料存放區 | 此卡片顯示按效能指標排序的前 10 個資料儲存區。您可以選擇標題，以遞增或遞減順序排列所選指標的前 10 個資料儲存區。卡片上的排序和篩選變更將保留，直到您變更或清除瀏覽器快取。使用「資料儲存區類型」下拉式清單選擇資料儲存區類型：NFS、VMFS 或 vVols。 


| ESXi 主機相容性卡 | 此卡片顯示所有 ESXi 主機（針對所選的 vCenter）是否依群組或類別遵循建議的 NetApp 主機設定。您可以選取 *Apply Recommended Settings* 連結來套用建議的設定。您可以選取主機的法規遵循狀態以查看主機清單。 
|===
