= 在 ONTAP tools 中設定網路存取
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
預設情況下，ONTAP tools 會自動將從 ESXi 主機探索到的所有 IP 位址新增至匯出原則，除非您設定網路存取。您可以修改匯出原則，僅允許特定 IP 位址存取；遭排除的 ESXi 主機將無法執行裝載作業。

.步驟
. 登入 vSphere 用戶端。
. 在外掛區段的捷徑頁面上選取 *NetApp ONTAP tools*。
. 在ONTAP工具的左側窗格中，前往 *設定* > *管理網路存取* > *編輯*。
+
若要新增多個 IP 位址，請以逗號、範圍、無類別域間路由 (CIDR) 表示法或這三者的組合分隔清單。

. 選擇*保存*。
