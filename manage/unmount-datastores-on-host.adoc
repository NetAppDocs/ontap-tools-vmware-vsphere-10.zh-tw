= 在 ONTAP tools 中卸載 NFS 和 VMFS 資料存放區
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
使用此工作可從 ESXi 主機取下 NFS 或 VMFS 資料儲存。不支援透過 UI 或 API 取下叢集層級的資料儲存。

從 ONTAP tools 10.6 開始，受保護的 VMFS 資料存放區的取下將被封鎖。

.步驟
. 登入 vSphere 用戶端。
. 右鍵點選 NFS 或 VMFS 資料儲存物件，然後選擇 *取下資料儲存設備*。
+
vSphere 用戶端會開啟一個對話框，列出裝載資料儲存設備的 ESXi 主機。如果資料儲存設備受到保護，ONTAP tools 會封鎖該要求，並顯示一則訊息，提示資料儲存設備受到保護，無法取下。

. 選取一或多個 ESXi 主機以卸載資料存放區。
+
您無法從所有主機上卸載資料存放區。使用者介面建議您改用刪除資料存放區作業。

. 選取 * 卸載 * 按鈕。
+
只有當主機移出受保護的主機叢集時，*取下資料存放區*選項才可用。




NOTE: 如果資料儲存受到保護，則必須先移除保護才能取下它。
