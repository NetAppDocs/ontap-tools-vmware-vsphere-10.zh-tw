= 編輯 ONTAP tools 備份設定
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
從 ONTAP tools for VMware vSphere 10.5 開始，備份預設為啟用，每 10 分鐘執行一次。您可以停用備份或變更備份頻率。

請勿停用備份，因為這會妨礙 ONTAP tools 維持較低的恢復點目標 （RPO）。停用備份不會刪除現有的備份檔案。您可以將備份頻率變更為 10 到 60 分鐘之間的值。

.步驟
. 從網路瀏覽器啟動 ONTAP 工具管理員： `\https://<ONTAPtoolsIP>:8443/virtualization/ui/`
. 使用您在部署期間提供的 VMware vSphere 管理員認證 ONTAP 工具登入。
. 選擇*設定* > *備份* > *編輯*選項。
. 在編輯視窗中，停用備份或變更備份頻率。
