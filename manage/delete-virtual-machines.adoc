= 清理 ONTAP 工具中的 VASA 配置
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
請依照以下步驟在 ONTAP tools 中完成 VASA 清理。


NOTE: 在開始 VASA 清理之前，請先移除所有 vVols 資料存放區。

.步驟
. 開啟 `\https://OTV_IP:8143/Register.html`以取消登錄外掛。
. 確認 vCenter Server 上不再提供外掛程式。
. 關閉 ONTAP tools for VMware vSphere 虛擬機器（VM）。
. 刪除適用於 VMware vSphere VM 的 ONTAP 工具。
