= 卸載 ONTAP 工具後移除 FlexVol 磁碟區
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在專用 ONTAP 叢集上部署 ONTAP tools for VMware vSphere 時，部署會建立許多未使用的 FlexVol® 磁碟區。移除 ONTAP tools 後，請刪除這些未使用的 FlexVol® 磁碟區，以避免可能的效能影響。

.步驟
. 從 ONTAP tools 管理節點 VM 判斷 ONTAP tools for VMware vSphere 的部署類型。執行下列命令以檢查部署類型：_cat /opt/netapp/meta/ansible_vars.yaml | grep -i protocol_
+
如果部署使用 iSCSI，也需要刪除 igroups。

. 取得FlexVol磁碟區的列表。_kubectl 描述持久性磁碟區 | grep internalName | awk -F'=' '{print $2}'_
. 從 vCenter Server 移除 VM 。請參閱 https://techdocs.broadcom.com/us/en/vmware-cis/vsphere/vsphere/8-0/vsphere-virtual-machine-administration-guide-8-0/managing-virtual-machinesvsphere-vm-admin/adding-and-removing-virtual-machinesvsphere-vm-admin.html#GUID-376174FE-F936-4BE4-B8C2-48EED42F110B-en["移除並重新登錄 VM 和 VM 範本"]。
. 刪除FlexVol磁碟區。參考 https://docs.netapp.com/us-en/ontap/volumes/delete-flexvol-task.html["刪除FlexVol 一個流通量"]。在 CLI 命令中輸入確切的FlexVol volume名稱以刪除磁碟區。
. 對於 iSCSI 部署，請從 ONTAP 儲存設備後端刪除 SAN igroup。請參閱 https://docs.netapp.com/us-en/ontap/san-admin/manage-san-initiators-task.html["檢視及管理SAN啟動器和群組"]。
