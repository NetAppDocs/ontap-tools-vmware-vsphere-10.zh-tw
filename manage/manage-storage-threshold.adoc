= 在 ONTAP tools 中管理儲存閾值
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以設定儲存設備閾值，以便在 Volume 或彙總容量達到一定層級時，在 vCenter Server 中接收通知。

.步驟
. 登入 vSphere 用戶端。
. 在捷徑頁面中，選取外掛程式區段下方的 * NetApp ONTAP tools* 。
. 在ONTAP工具的左側窗格中，前往 *設定* > *閾值設定* > *編輯*。
. 在「編輯臨界值」視窗中，分別在「接近滿」和「滿」欄位中輸入所需值，然後選擇「儲存」。
+

NOTE: 您可以將臨界值還原為建議的預設值：「接近滿」為 80，「滿」為 90。
