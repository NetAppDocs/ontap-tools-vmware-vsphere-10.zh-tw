= 在 ONTAP tools 中變更憑證驗證標誌
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
預設情況下，ONTAP 儲存設備後端憑證已啟用憑證驗證。如有需要，您可以將憑證驗證標誌設為 false 以繞過 SAN 憑證檢查。此設定不適用於 vCenter Server 憑證。

.開始之前
您需要維護使用者憑證。

.步驟
. 登入 vCenter 伺服器。
. 找到 ONTAP tools 虛擬機器並開啟 Web 主控台。
. 請使用 `maint`憑證登入。
. 進入 `1`選擇“應用程式配置”選單。
. 輸入 `3`以變更憑證驗證旗標。
+
維護控制台顯示憑證驗證標誌狀態並提示您進行變更。

. 輸入“y”切換標誌或輸入“n”取消。


啟用憑證驗證後，ONTAP tools 會檢查所有儲存設備後端是否使用帶有主體替代名稱 （SAN） 的憑證。如果任何儲存設備後端使用的憑證不包含 SAN，則無法啟用驗證。啟用此標誌之前，請確認所有儲存設備後端均使用基於 SAN 的憑證。如果停用此標誌，ONTAP tools 將略過所有已設定儲存設備後端的憑證驗證。



[[verify-san-based-certificates-for-storage-backends]]
== 驗證儲存後端的 SAN 型憑證

為確保通訊安全和正確驗證，請確認所有儲存後端均使用基於 SAN 的憑證：

. 檢查 ONTAP 管理憑證是否包含主體別名 (SAN) 項目。
. 確認 SAN 條目與 ONTAP 管理 IP 位址或 DNS 名稱（或兩者）相符。
. 確保用於上線 ONTAP 的詳細資料與憑證的 SAN 項目中的 IP 位址或 DNS 名稱相符。


這些步驟有助於防止憑證驗證問題，並確保 ONTAP 系統安全整合。
