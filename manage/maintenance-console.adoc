= ONTAP tools 維護主控台
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP tools for VMware vSphere的維護控制台可讓您管理應用程式、系統和網路設定。您可以更新管理員和維護密碼、產生支援包、設定日誌等級、管理 TLS 設定以及啟用遠端診斷。

部署 ONTAP tools for VMware vSphere 後，如果維護主控台無法存取，請從 vCenter Server 安裝 VMware Tools。使用 `maint`部署期間設定的使用者名稱和密碼登入。在維護主控台或根目錄登入主控台中使用 *nano* 編輯檔案。


NOTE: 啟用遠端診斷時，請為  `diag` 使用者設定密碼。

使用已部署的 ONTAP tools for VMware vSphere 的*摘要*索引標籤來存取維護主控台。選擇 image:../media/launch-maintenance-console.gif["播放按鈕"] 以啟動維護主控台。
