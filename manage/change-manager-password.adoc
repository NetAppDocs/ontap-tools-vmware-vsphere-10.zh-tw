= 變更 ONTAP 工具管理員密碼
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以在 ONTAP tools Manager 中變更系統管理員密碼。

.步驟
. 從網路瀏覽器啟動 ONTAP 工具管理員： `\https://<ONTAPtoolsIP>:8443/virtualization/ui/`
. 使用您的ONTAP tools for VMware vSphere管理員憑證。
. 選擇右上角的*系統管理員*圖示，然後選擇*變更密碼*。
. 在「變更密碼」對話方塊中，輸入舊密碼和新密碼。請審查對話方塊中顯示的密碼要求。
. 選擇“更改”以應用更改。
