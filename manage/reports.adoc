= ONTAP tools for VMware vSphere 報告
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP tools for VMware vSphere 外掛提供報告，可協助您監控由 ONTAP 儲存設備支援的虛擬機器和資料存放區。若要檢視報告，請在 vSphere Client 的捷徑區段中選擇 ONTAP tools for VMware vSphere 外掛圖示，然後選擇 *Reports* 索引標籤。

「虛擬機器」報告列出已探索到的虛擬機器，這些虛擬機器在 ONTAP 儲存設備型資料存放區上至少有一個磁碟，以及效能計量。擴充虛擬機器記錄後，即可查看其磁碟的所有資料存放區資訊。

資料存放區報告列出 ONTAP tools for VMware vSphere 探索到的、使用 ONTAP 儲存設備的資料存放區，以及效能計量。

您可以使用「Manage Columns」選項來隱藏或顯示欄位。
