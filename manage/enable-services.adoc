= 啟用 ONTAP tools 服務
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
使用 ONTAP tools Manager 啟用選用服務，例如 VASA Provider、vVols 組態導入和災難恢復 （SRA）。

.步驟
. 從網路瀏覽器啟動 ONTAP 工具管理員： `\https://<ONTAPtoolsIP>:8443/virtualization/ui/`
. 使用您在部署期間提供的 VMware vSphere 管理員認證 ONTAP 工具登入。
. 在「總覽」區段中，選取「編輯應用裝置設定」。
. 在「*服務*」部分，啟用您需要的選用服務，例如 VASA Provider、vVols 組態匯入和災難恢復 （SRA）。
+
首次啟用這些服務時，請建立 VASA Provider 和 SRA 憑證。

+
** 使用這些憑證在 vCenter 伺服器上註冊並啟用 VASA Provider 和 SRA 服務。
** 使用者名稱只能包含字母、數字和底線。
** 密碼長度必須介於 8 到 256 個字元之間。





NOTE: 在停用任何選用服務之前，請確保由 ONTAP tools 管理的 vCenter Server 執行個體未使用該服務。

+ 僅啟用 VASA Provider 服務時，「允許匯入 vVols 組態」選項才會顯示。此選項可將 vVols 資料從 ONTAP tools 9.x 移轉至 ONTAP tools 10.6。
