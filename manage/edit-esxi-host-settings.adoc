= 使用ONTAP VMware ESXi工具修改ESXi主機設定
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
使用 VMware vSphere 中的 ONTAP tools 儀表板來識別組態問題、審查NetApp針對所選 ESXi 主機的建議設定，並套用這些設定。

.開始之前
ESXi 主機系統 portlet 顯示 ESXi 主機設定有問題。選擇問題以查看主機名稱或 IP 位址。

.步驟
. 登入 vSphere Client。
. 在「捷徑」頁面上，選取「外掛」區段下的 *NetApp ONTAP tools*。
. 前往 ONTAP tools for VMware vSphere 外掛的總覽儀表板上的 *ESXi 主機法規遵循* portlet。
. 選擇*套用建議設定*連結。
. 在「套用推薦主機設定」視窗中，選擇要套用 NetApp 建議主機設定的主機，然後選擇「下一步」。
+

NOTE: 您可以展開 ESXi 主機以查看目前的值。

. 在「設定」頁面上，根據需要選擇建議值。
. 在總結窗格中，檢查各項值並選擇「完成」。您可以在「最近任務」面板中追蹤進度。
