= 在 ONTAP tools 中擴充 vVols 資料儲存庫
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在 vCenter 物件檢視中右鍵點選資料存放區物件時，外掛區段會顯示 ONTAP tools for VMware vSphere 支援的行動。可用的行動取決於資料存放區類型和目前使用者的 Privileges。


NOTE: 此程序不適用於基於 ASA r2 系統的 vVols 資料儲存。

.步驟
. 從 vSphere Client 首頁、選取 * 主機與叢集 * 。
. 在導覽窗格中，選取包含資料存放區的資料中心。
. 在資料存放區上按一下滑鼠右鍵、然後選取 * NetApp ONTAP tools* > * 將儲存區新增至資料存放區 * 。
. 在「建立或選擇磁碟區」視窗中，您可以建立新磁碟區或從現有磁碟區中進行選擇。請依照螢幕上的指示進行選擇。
. 在 * 摘要 * 視窗中，檢閱選項並選取 * 展開 * 。您可以在「最近的工作」面板中追蹤進度。
