= 將 NTP 伺服器新增至 ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
輸入 NTP 伺服器詳細資料，以同步 ONTAP 工具應用裝置的時間時鐘。


NOTE: 從 ONTAP tools for VMware vSphere 10.6 開始，時間同步守護程式由 ntpd 改為 chronyd。升級至 10.6 時，現有的 NTP 伺服器設定會自動移轉。無需手動重新設定。

.步驟
. 從網路瀏覽器啟動 ONTAP 工具管理員： `\https://<ONTAPtoolsIP>:8443/virtualization/ui/`
. 使用您在部署期間提供的 VMware vSphere 管理員認證 ONTAP 工具登入。
. 選擇 * 設定 * > * NTP 伺服器 * > * 編輯 * 選項。
. 請輸入以逗號分隔的完整網域名稱 (FQDN) 或 IPv4 位址。
+
重新整理畫面以查看更新的值。
