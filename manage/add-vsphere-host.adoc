= 將 VMware vSphere 主機新增至 ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
將新的 VMware vSphere 主機新增至 ONTAP tools for VMware vSphere，以便管理和保護主機資料存放區。

.步驟
. 請依照下列步驟將主機新增至 VMware vSphere 叢集 https://techdocs.broadcom.com/["Broadcom 技術文件"]。
. 新增主機後，請前往 ONTAP tools 主選單，然後在總覽面板中選取 *探索*，或等待已排程的主機探索完成。


.結果
新主機現在已由 ONTAP tools for VMware vSphere 探索並代管。您現在可以管理主機上的資料存放區。
