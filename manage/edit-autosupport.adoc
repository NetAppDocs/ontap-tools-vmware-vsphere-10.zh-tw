= 編輯 ONTAP tools AutoSupport 設定
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
AutoSupport 在您首次設定 ONTAP tools for VMware vSphere 時預設為啟用。啟用後 24 小時，系統會將訊息傳送給技術支援。



[[disable-autosupport]]
== 停用 AutoSupport

當您停用AutoSupport時，您將不再獲得主動支援和監控。


NOTE: 保持 AutoSupport 啟用狀態，因為它有助於加快問題偵測和解決速度。即使 AutoSupport 停用，系統仍會繼續在本機收集和儲存資訊，但不會透過網路傳送報告。

.步驟
. 從網路瀏覽器啟動 ONTAP 工具管理員： `\https://<ONTAPtoolsIP>:8443/virtualization/ui/`
. 使用您在部署期間提供的 VMware vSphere 管理員認證 ONTAP 工具登入。
. 選擇 * 設定 * > * 遙測 * > * 編輯 * 選項。
. 取消選取 AutoSupport 選項並儲存變更。




[[update-autosupport-proxy-url]]
== 更新 AutoSupport Proxy URL

更新AutoSupport代理 URL，以便AutoSupport功能透過代理伺服器路由數據，實現安全傳輸。

.步驟
. 從網路瀏覽器啟動 ONTAP 工具管理員： `\https://<ONTAPtoolsIP>:8443/virtualization/ui/`
. 使用您在部署期間提供的 VMware vSphere 管理員認證 ONTAP 工具登入。
. 從側邊列選取 * 設定 * 。
. 選擇 * 設定 * > * 遙測 * > * 編輯 * 選項。
. 輸入有效的 * Proxy URL* 並儲存變更。
+
如果停用 AutoSupport ，則 Proxy URL 也會停用。
