= 將 ONTAP tools for VMware vSphere 9.xx 移轉至 10.6
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
從 ONTAP tools for VMware vSphere 9.xx 移轉至 10.6 需要根據您的資料存放區類型採取不同的步驟。

您可以將 ONTAP tools for VMware vSphere 9.12D1、9.13D2 和 9.13P2 版本移轉至 ONTAP tools for VMware vSphere 10.6。

如果您的設定包含 NFS 和 VMFS 資料存放區，但沒有 vVols 資料存放區，請卸載 ONTAP tools 9.xx 並部署 ONTAP tools 10.6。如果您的設定包含 vVols 資料存放區，請移轉 VASA Provider 和 SRA。

下表概述了這兩種不同場景下的遷移過程。

|===
| *如果設定有 vVols 資料儲存* | *如果設定僅包含 NFS 和 VMFS 資料儲存* 


| 步驟：1.link:../migrate/sra-vasa-migration.html["遷移 VASA 提供程序"] 2.  https://techdocs.broadcom.com/us/en/vmware-cis/vsphere/vsphere/8-0/vsphere-storage-8-0/storage-policy-based-management-in-vsphere/creating-and-managing-vsphere-storage-policies.html["建立虛擬機器儲存策略"] | 步驟：1.從您的環境中移除 ONTAP tools 9.xx。請參閱 NetApp 知識庫中的 https://kb.netapp.com/data-mgmt/OTV/VSC_Kbs/OTV_How_to_remove_OTV_9_12_from_your_environment["如何從您的環境中刪除 OTV 9.xx"]。2.link:../deploy/quick-start.html["部署與設定 ONTAP tools for VMware vSphere 10.6"] 3.link:../migrate/sra-vasa-migration.html["更新「SRA」"] 4. https://techdocs.broadcom.com/us/en/vmware-cis/vsphere/vsphere/8-0/vsphere-storage-8-0/storage-policy-based-management-in-vsphere/creating-and-managing-vsphere-storage-policies.html["建立虛擬機器儲存策略"] 
|===

NOTE: 從 ONTAP tools for VMware vSphere 9.xx 移轉至 10.6 後，使用 NVMe/FC 協定的 vVols 資料存放區將無法運作，因為 ONTAP tools 10.6 僅支援 VMFS 資料存放區的 NVMe-oF 協定。

== 移轉後

請核實以下內容：

* 資料儲存可從 vCenter Server 存取。
* VM 儲存設備原則已按預期對應。
* 已設定資料存放區的保護和複寫狀態顯示正常。
