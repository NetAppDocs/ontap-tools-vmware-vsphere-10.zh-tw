= 使用 ONTAP tools 設定叢集以保護資料存放區
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
使用 ONTAP tools for VMware vSphere 設定叢集組態（主機到儲存設備的鄰近性）設定，為您的虛擬化環境實現高效的資料存放區保護和簡化的容錯移轉管理。

.開始之前
* 請確認您擁有 vSphere 的管理員權限。
* 叢集組態設定適用於統一配置和非統一配置，而存取設定僅適用於 AFD 類型的關係。


.步驟
. 在 vSphere 用戶端中，右鍵單擊主機叢集，然後選擇 *Configure cluster protection*。
+

NOTE: 如果叢集已有叢集組態，則此選項可讓您編輯現有組態。

. 在「組態類型」視窗中：
+
.. 選擇 *Uniform* 以允許兩個故障域中的主機存取兩個站台的儲存資源。故障域是一組硬體和基礎架構元件。請將每台主機指派到兩個站台的某個故障域。
.. 選擇 *Non-uniform* 以限制每個站台的主機只能存取其各自站台的儲存設備。並據此將主機指派到故障網域。
.. 輸入故障網域名稱。預設名稱為「Site A」和「Site B」。您可以編輯這些值。站台名稱對應至來源和目標故障網域。UI 會在您輸入時驗證項目，並針對不支援的字元或超過字元限制的值顯示訊息。
+

NOTE: 組態類型一旦設定便無法修改。若要變更組態類型，請刪除叢集組態並使用所需設定建立新的組態。



. 選擇*下一步*。
. 在「主機」視窗中，將每台主機指派到來源故障域或目標故障域。所有主機都必須指派，且一台主機不能同時屬於兩個站台。精靈中顯示的站台名稱即為來源和目標故障域的名稱。所有主機指派完成後，「下一步」按鈕才會啟用。
. 選擇*下一步*。
. 在「儲存 SVM 對等體」頁面上，將每個 SVM 指派到對應的站台。您可以指派多個 SVM 對等體，但每個站台至少需要指派一個。將 SVM 指派到某個站台時，其對等 SVM 會自動指派到另一個站台。
. 選擇*下一步*。
. 請查看「摘要」頁面。確認各故障網域的叢集組態設定。
. 選擇 *Create* 以套用組態。
. 檢視或編輯現有叢集保護組態：
+
.. 前往 ONTAP tools 外掛檢視。
.. 導覽至「保護」>「叢集保護組態」。
.. 選擇叢集以檢視其目前組態。
.. 按一下垂直省略號，然後選取「編輯」以修改組態。精靈會顯示目前設定以供編輯。
+
image:../media/edit-protection.png["編輯叢集保護組態"]





.結果
組態已套用，您可以在 ONTAP tools 外掛中檢視或編輯它。
