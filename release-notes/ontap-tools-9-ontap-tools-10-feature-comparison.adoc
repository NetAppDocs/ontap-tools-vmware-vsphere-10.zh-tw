= ONTAP tools for VMware vSphere 9 與 10 功能比較
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
了解為什麼從 ONTAP tools for VMware vSphere 9 移轉至 ONTAP tools for VMware vSphere 10.2 或更新版本可能是適合您環境的正確選擇。


NOTE: 如需最新的相容性資訊，請參閱 https://mysupport.netapp.com/matrix["NetApp 互通性對照表工具"^]。

有關 ONTAP tools 9.x 的最新停止支援資訊，請參閱 https://mysupport.netapp.com/site/info/version-support["軟體版本支援"^]。

[cols="20%,25%,30%"]
|===
| 特徵 | ONTAP工具 9.13 | ONTAP工具 10.2 及更高版本 


| 關鍵價值主張 | 透過增強安全性、法規遵循和自動化功能，簡化從第 0 天到第 2 天的作業。每個 ONTAP tools 應用裝置僅支援一台 vCenter Server。 | 擴展支援，新增對 VMFS 的 FC 和僅對 VMFS 的 NVMe-oF 支援。易於使用 NetApp SnapMirror，簡化 vSphere 城域儲存叢集的設定，以及三站點 VMware Live Site Recovery 支援。每個 ONTAP tools 應用裝置支援多個 vCenter Server 執行個體，從而減少應用裝置數量和整體資源需求。 


| ONTAP發布資格 | ONTAP 9.9.1 升級至ONTAP 9.16.1 | ONTAP tools 10.2 適用的 ONTAP 9.12.1 至 9.15.1。ONTAP tools 10.3 適用的 ONTAP 9.14.1、9.15.1、9.16.0 和 9.16.1。ONTAP tools 10.4 適用的 ONTAP 9.14.1、9.15.1、9.16.0 和 9.16.1。使用 ASA r2 系統時，ONTAP tools 10.4 需要 ONTAP 9.16.1P3 及更新版本。ONTAP tools 10.5 適用的 ONTAP 9.15.1、9.16.1 和 9.17.0；ONTAP tools 10.6 適用的 ONTAP 9.16.1、9.17.1、9.18.1 和 9.19.1，以及 ASA r2 版本 9.16.1P3、9.17.1、9.18.1 和 9.19.1。 


| VMware 版本支持 | vSphere 7.x-8.x VMware Site Recovery Manager (SRM) 8.5 至 VMware Live Site Recovery 9.0 | vSphere 7.x-8.x vSphere 9.0（從 ONTAP tools 10.5 起）VMware Site Recovery Manager (SRM) 8.7 至 VMware Live Site Recovery 9.0、9.0.1、9.0.2、9.0.3 和 9.0.4 


| 協議支持 | NFS 和 VMFS 資料儲存：NFS（v3 和 v4.1）、VMFS（iSCSI 和 FCP） | NFS 和 VMFS 資料儲存：NFS （v3 和 v4.1）、VMFS（iSCSI/FCP/NVMe-TCP 和 NVMe-FC） 


| 可擴展性 | 主機和虛擬機器：300 台主機，最多 1 萬台虛擬機器；資料儲存：600 個 NFS 存儲，最多 50 個 VMFS 儲存。 | 主機和虛擬機器：600 台主機 


| 可觀察性 | 效能、容量和主機合規性儀表板動態虛擬機器和資料儲存區報告 | 更新了效能、容量和主機合規性儀表板動態虛擬機器和資料儲存區報告 


| 資料保護 | SRA 複製適用於 VMFS 和 NFS。  SCV整合和互通性，可用於備份。 | SRA 複寫支援 iSCSI VMFS 和 NFS v3 資料存放區，提供三站點保護，並結合 SMAS 和 VMware Live Site Recovery。SRA 支援 FCP 與 VMFS。ONTAP tools 10.6 提供精細的資料存放區保護和一致性群組管理。*注意：* 在 ONTAP tools 10.x 中，SRM 支援共享的站點，從而增強了擴充性並提升了效能。 


| VASA 提供程序支援 | VASA 4.0 | VASA 3.0 
|===
